# 🐙 Anuario – Formación en GitHub · Ficha 3410945

¡Bienvenidos! Este es el repositorio de nuestra clase. Aquí cada aprendiz deja su perfil usando **fork** y **Pull Request**, como se contribuye a los proyectos de código abierto en todo el mundo.

## ¿Cómo agrego mi perfil?
1. Haz **fork** de este repositorio (botón arriba a la derecha).
2. Clona **tu fork** en tu computador.
3. Crea una rama: `git switch -c agregar-perfil-tu-usuario`
4. Crea el archivo `aprendices/tu-usuario.md` copiando el formato de `aprendices/instructor.md`.
5. Haz commit, push y abre un **Pull Request** hacia este repositorio.
6. Espera la revisión del instructor. Si te pide cambios, corrígelos en la misma rama.

## Reglas
- Solo crea **tu propio archivo**. No modifiques los archivos de otros ni este README.
- El nombre del archivo debe ser tu usuario de GitHub, en minúsculas y terminado en `.md`.
- Escribe con respeto: este repositorio es público.
